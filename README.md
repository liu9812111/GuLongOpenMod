# 古龙风云录 开放 Mod（GuLongOpenMod）

《古龙风云录》已经全平台下架。这个项目想让还喜欢它的人，继续一起给它添内容：

- 喜欢写故事的，续写主线、补支线、给配角加戏；
- 喜欢武侠动作的，设计新招式、新武学、新兵器；
- 喜欢折腾数值的，调平衡、加装备、做挑战战斗。

本仓库提供一个 **BepInEx 插件** 和一套 **内容包** 规则。每个人做的东西都是一个独立的内容包，
只写自己新增或修改的那几行表格，插件在游戏读表时自动合并。多人的内容互不覆盖，可以自由组合。

> **声明**：这是玩家自发的非官方项目，与游戏的开发商、发行商无关。
> 仓库里 **不包含任何游戏文件**（表格、图片、模型、音频），需要你自己拥有正版游戏。
> 也请不要往仓库里提交游戏原有的资源或其他游戏的资源。

---

## 我只想玩

1. 按 [docs/安装.md](docs/安装.md) 装好 BepInEx 5，编译插件（需要 .NET SDK，一条命令）。
2. 想装哪个内容包，就把 `packs/` 里对应的文件夹复制到 `游戏目录\Mod\Packs\`（编译时默认全部自动复制）。
3. 进游戏。日志 `BepInEx\LogOutput.log` 里能看到加载了哪些包。

## 仓库结构

```
plugin/      插件源码（C#，BepInEx 5）
packs/       内容包，一个文件夹一个
  yinlong/     示例：招式书「亢龙有悔」
  shenlong/    示例：招式书「神龙摆尾」
  longzhan/    示例：招式书「龙战于野」
  devtools/    开发用：木桩测试敌人
docs/        中文文档
tools/       validate.py：内容包校验（提交前跑一下，GitHub 也会自动跑）
```

## 插件功能

- **内容包**：增量表合并、按游戏路径提供图片 / json 等文件、改招、BGM；F5 热重载。
- **制作辅助**：招式预览（F6）、改招重载（F7）、学会招式（F10）、发道具（Ctrl+F10）、木桩测试战斗（F11）、导出演出结构（F12）。
- **游戏调整**（都可在 F1 配置里开关）：学技能不吃书、上阵人数、技能栏位、互动点常亮、战后回满、推理一键完成（F9）、BGM 替换、主角改名。
