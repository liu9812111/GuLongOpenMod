# Id 前缀登记

每个内容包新增的 Id（招式、道具、奖励、对话、任务……）都要以自己的前缀开头，避免和别人的内容撞名。
规则见 [内容包格式.md](内容包格式.md#id-前缀)。

**登记方法**：在下表末尾加一行，和你的内容包一起提交。前缀不能和已有的重叠（比如已经有 `xk_`，就不能用 `xk` 或 `xk_a`）。
提交时 `tools/validate.py` 也会检查仓库里所有包的前缀有没有重叠。

| 前缀 | 作者 | 内容包 | 备注 |
|---|---|---|---|
| `xk_`、`itxk` | James | yinlong | 示例包 |
| `dev_` | James | devtools | 开发测试用 |
