# 教程：做第一本武学书

目标：做一本拳掌招式书「开山掌」，角色读了学会新招「开山掌」，能在战斗里用。全程只改文本文件，不用编程。

照着做大约半小时。先确认已经按 [安装.md](安装.md) 装好插件，并且进游戏能看到 `银龙推掌` 包加载了。

---

## 第 1 步：建自己的包

1. 复制 `packs\yinlong\` 整个文件夹，改名为你的包 id，比如 `zs_kaishan`（英文小写）。
2. 删掉里面的 `skillmod\` 文件夹（第一本书先不改特效）。
3. 用记事本打开 `pack.json`，改成你的：

```json
{
  "id": "zs_kaishan",
  "name": "开山掌",
  "version": "1.0.0",
  "authors": ["张三"],
  "description": "一本拳掌招式书：开山掌。",
  "idPrefix": ["zs_"],
  "requires": [],
  "order": 0
}
```

`idPrefix` 是你的专属前缀，后面所有新 Id 都用它开头（规则见 [内容包格式.md](内容包格式.md#id-前缀)）。

本教程用到三个 Id：

| 东西 | Id |
|---|---|
| 招式 | `zs_s0001` |
| 招式书（道具） | `zs_book01` |
| 发书的奖励 | `zs_book01_get` |

---

## 第 2 步：招式（tables\SkillItem.txt）

打开 `tables\SkillItem.txt`，把数据行改成：

- `Id` → `zs_s0001`
- `Name` → `开山掌`
- `Description` → 你的招式说明
- `AnimationName` → 招式演出。先用原版现成的：`gl_skill_empty_107`（推掌的动作）。
  想换别的动作：游戏里按 **F6** 打开招式预览，左边列出所有招式，选中能看到演出名、直接预览效果。
- 数值类列（`BaseDamage` 基础伤害、`NeedMp` 耗内力、`MaxRange` 距离……）按需要调，含义见 [表格说明.md](表格说明.md#skillitem)。

> 注释行（`#` 开头）可以随便改、随便删。

## 第 3 步：招式书（tables\NormalInventoryItem.txt）

```
Id	Name	Story	Price	Category	Rarity	Icon	Skill	WeaponType
zs_book01	开山掌	「一掌既出，山岳为之动摇。」	3000	FightBook	2	zs_book01	zs_s0001	Fight
```

- `Category`：书的种类。`FightBook` 拳掌、`SwordBook` 剑、`BladeBook` 刀、`DaggerBook` 短兵、`DartsBook` 暗器。
- `Skill`：读了学会哪个招式，填第 2 步的 Id。
- `WeaponType`：和书的种类对应：拳掌 `Fight`、剑 `Sword`、刀 `Blade`、短兵 `Dagger`、暗器 `Darts`。
- `Rarity`：稀有度，原版书是 0~4。`Icon`：图标文件名（下一步）。

## 第 4 步：图标

画一张 PNG（建议 300×300，背景透明），命名为 `zs_book01.png`，放到
`files\Image\Icon\Item\zs_book01.png`，再删掉复制过来的 `itxk0002.png`。

没准备好图标也可以先填原版某本书的 Icon 值，之后再换。

## 第 5 步：发书的奖励（tables\RewardItem.txt）

```
Id	Remark	IsShowMessage	Rewards
zs_book01_get	获得招式书_开山掌	TRUE	{ 'LogicalNode' : [ { 'RewardProps' : 'zs_book01', 1}  ], 0} 
```

`Rewards` 列照抄，只把 `zs_book01` 换成你的书 Id。以后剧情、宝箱、商店都可以通过它发这本书。

---

## 第 6 步：进游戏测试

1. 把你的包文件夹复制到 `游戏目录\Mod\Packs\`（或者放进仓库 `packs\` 后重新编译，会自动复制）。
2. 进游戏读档，看 `BepInEx\LogOutput.log`：

   ```
   [内容包] 已加载 3 个：…，开山掌(zs_kaishan) 1.0.0
   [内容包] SkillItem：开山掌(zs_kaishan) 新增 1 行，修改 0 行
   ```

   如果有 `[警告]` / `[错误]`，按提示改。

3. 按 **F1** → 「武学测试」→「发放道具ID」改成 `zs_book01`，回到游戏按 **Ctrl+F10**，右上角提示「获得 开山掌×1」。
4. 打开背包，用书 → 选角色学会 → 武学界面装备。
5. 按 **F11** 进木桩测试战斗（需要 `devtools` 包），用新招打一下。建议先存档。

**改了表想看效果**：保存文件后在游戏里按 **F5** 重新加载，不用重启。已经在背包里的书、已经学会的招，重新打开界面或重新进战斗就是新数值。

---

## 第 7 步：检查和提交

在仓库根目录运行：

```
python tools/validate.py
```

0 个错误就可以按 [CONTRIBUTING.md](../CONTRIBUTING.md) 提交了。

## 进阶

- 给招式加炫酷特效、换颜色：[改招.md](改招.md)（`yinlong` 包就是给推掌加了一条龙）。
- 让书出现在商店、宝箱或剧情奖励里：需要改对应的表（ShopItem 等），整理中。
