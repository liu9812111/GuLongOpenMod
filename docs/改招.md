# 改招：修改招式演出

招式出手时的动作、特效、镜头叫「演出」（游戏里是 Timeline），SkillItem 表的 `AnimationName` 列就是演出名。
我们没法凭空做新动作，但可以 **拿原版演出当底子，把别的招式的特效借过来、改颜色、改大小、挪位置**。

例子：`packs\yinlong\skillmod\xk_yinlong.json` 把「银枪穿云」的龙借到了「推掌」上，并染成金色。

---

## 文件放哪、叫什么

放在内容包的 `skillmod\` 下，**文件名 = 生成的演出名**：

- 文件名是 **新名字**（推荐，如 `zs_kaishan.json`）→ 生成一个新演出，原版不受影响。
  在 SkillItem 表里把你的招式的 `AnimationName` 填成 `zs_kaishan`。
- 文件名和 **原版演出同名**（如 `gl_skill_empty_107.json`）→ 直接改掉原版，所有用这个演出的招式都会变。慎用。

改完 json 在游戏里按 **F7**（或 F5）立即生效，F6 预览窗口开着会自动重播。
注意改的要是游戏实际读的那份：建议在 F1 里设好「开发目录」，直接改仓库里的文件（见 [工具与调试.md](工具与调试.md#开发目录直接读仓库里的内容包)）。

## 找演出名、特效名：F6 预览

游戏里按 **F6** 打开招式预览窗口：

- 左边列出 SkillItem 表里所有招式，选中就在角色身上播放，PageUp / PageDown 切换。
- 窗口里显示演出名、攻击方的特效列表（名字、出现时间）、命中时间。
- 可以调播放速度、选受击方。

用它找到 **想当底子的动作** 和 **想借的特效**，记下名字。

## 格式

支持 `//` 注释。

```jsonc
{
  "base": "gl_skill_empty_107",     // 底子演出。不写 = 和文件同名的原版演出

  "add": [                          // 从别的演出借攻击方的特效
    {
      "from": "gl_skill_both_014",  // 从哪个演出借
      "fx": "VFX_Dragon_dash_attack", // 特效名（F6 里看到的）
      "time": 0.0                   // 其他参数见下表
    }
  ],

  "edit": [                         // 调整底子里本来就有的特效（不用写 from）
    { "fx": "某特效", "index": 0, "scale": 0.5 }
  ],

  "remove": [ "某特效" ]             // 删掉底子里这些名字的特效（同名的全删）
}
```

### 每个特效可调的参数

| 参数 | 说明 | 例 |
|---|---|---|
| `fx` | 特效名 | `"VFX_Dragon_dash_attack"` |
| `index` | 同名特效有好几个时，指定第几个（从 0 数） | `0` |
| `time` | 出现时间（秒）。对照 F6 里的命中时间调 | `0.3` |
| `speed` | 播放速度倍率 | `1.2` |
| `scale` | 大小倍率 | `1.5` |
| `move` | 位置偏移（米）`[左右, 上下, 前后]`，正数 = 右 / 上 / 前 | `[0, 0.5, 1]` |
| `rotate` | 再转多少度 `[俯仰, 左右转, 翻滚]` | `[0, 90, 0]` |
| `color` | 颜色倍率 `[红, 绿, 蓝]`，1 = 不变。白色 / 银色的特效乘上去就变成这个颜色 | `[1, 0.6, 0.2]` |
| `hue` | 色相旋转（度，-180~180），给彩色特效整体换色。红→绿 约 120 | `120` |
| `brightness` | 亮度倍率 | `1.5` |
| `props` | 直接设材质属性：颜色写 `[r,g,b]`（保留原透明度）或 `[r,g,b,a]`，数值写 `[x]` | `{ "_RimColor": [1, 0.7, 0.15], "_Metallic": [1] }` |

### 换色怎么选

- **粒子类特效**（火花、气流、光圈）：用 `color`，不行就用 `hue`。
- **模型类特效**（比如那条龙）：颜色在材质上，用 `props`。日志里会列出这个特效有哪些材质属性、原来是多少。
  - 龙的例子：`_Color` 是龙身颜色，`_RimColor` 是外层玻璃质感的边缘光（银色感主要来自它）。
  - 原版很多颜色是很亮的值（大于 1），所以 `brightness` 要调到 2~3 才明显。想只提亮边缘光，可以给 `_RimColor` 较大的数，如 `[3, 2.1, 0.45]`。

## 常见问题

- **按 F7 没变化**：看日志里 `[改招]` 开头的行，json 写错会提示哪里有误。
- **特效位置不对**：借来的特效是挂在角色身上某个部位的，不同动作的姿势不同，用 `move` / `rotate` 微调。
- **招式在战斗里没变**：确认 SkillItem 里你的招式的 `AnimationName` 写的是 json 文件名（不含 `.json`）。
