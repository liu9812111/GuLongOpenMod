# 表格说明

游戏的数据都在表格里。这里列出做内容最常用的几张表的列（中文是原表自带的注释，有的不太准，以实际效果为准）。
「例子」是原版某一行的值，方便理解格式。

**欢迎补充**：你搞清楚了某一列的作用，直接改这个文档提交上来。

## 常用取值

| 用在 | 取值 |
|---|---|
| 招式 `Category`、书的 `WeaponType` | `Fight` 拳掌、`Sword` 剑、`Blade` 刀、`Dagger` 短兵、`Darts` 暗器 |
| 书的 `Category` | `FightBook` `SwordBook` `BladeBook` `DaggerBook` `DartsBook`（招式书，`Skill` 列填招式 Id）；`HeartFormula`（心法书，`Perception` 列）；`NormalBook` |
| `TRUE` / `FALSE` | 布尔值，全大写 |
| 坐标 | `x, y, z` 形式，如 `0.000, 0.000, 0.000` |

## 招式的类型和攻击范围（SkillItem）

取值来自游戏源码里的枚举，括号里是原版的使用次数，供参考。

| 列 | 取值 |
|---|---|
| `DamageType` 伤害分类 | `Damage` 攻击（473）、`Buff` 增益（243）、`Recover` 恢复（86）、`Debuff` 减益（60）、`Jump` 跳跃（23）、`Collision` 冲撞（18）、`Charge` 冲锋（17）、`Summon` 召唤、`Throwing` 道具、`Catch` 捉影 |
| `SkillType` 施放类型 | `Immediately` 瞬发（864）；集气：`RechargeDirection` 指定方位（42）、`RechargeTarget` 指定目标（14）、`RechargeTile` 指定格子（6），集气时间看 `RechargeTickCost` |
| `SkillEffect` 作用类型 | `Once` 单次（几乎全部）；`Wave` 波段（配合 `WaveCount` / `WaveDuration` / `HitCount`） |
| `TargetType` 目标对象 | `Hostile` 敌方、`Friendly` 友方、`All` 敌我不分、`Tile` 地板（选格子）、`FriendTile` 友方地板、`Special` 特定目标 |
| `TargetArea` 范围形状 | 见下表 |

战场是**六边形格子**。`TargetArea` 和距离列一起决定打到哪些格子：

| `TargetArea` | 形状 | 用到的列 | 原版例子 |
|---|---|---|---|
| `Ring` | 选距离内的一个目标，再以它为中心打一圈 | `MaxRange` / `MinRange` 选目标的距离；`SplattingRange` 溅射半径（0 = 只打目标） | 推掌：距离 1、溅射 0 = 打身边一个人 |
| `RingGroup` | 同上，群体版 | 同上 | |
| `Line` | 朝一个方向的直线，**碰到第一个敌人就停**（单体） | `MinRange`~`MaxRange` | |
| `LineGroup` | 朝一个方向的直线，**贯穿**，直线上的敌人全打 | 打第 `MinRange` 到第 `MaxRange` 格 | 银枪穿云：1~3 = 前方 3 格 |
| `WideLineGroup` | **宽直线**：正前方及左前、右前共 3 格，各自再往前延伸，形成 3 格宽的带状区域 | `MaxRange` = 长度 | 正阳佛手：长 3 = 3×3 |
| `Fan` | 扇形 | `MinRange`~`MaxRange` | |

例：「前方 3 格直线贯穿」= `TargetArea` 填 `LineGroup`，`MinRange` 填 1，`MaxRange` 填 3，`SkillType` 用 `Immediately`。

## 表之间的关系（做武学书时）

```
NormalInventoryItem（书） ──Skill──▶ SkillItem（招式） ──AnimationName──▶ 演出（原版 或 skillmod/*.json）
        ▲
RewardItem（奖励）──'RewardProps' : '书Id'
        ▲
剧情 / 商店 / 宝箱 / Ctrl+F10
```

## 剧情相关（第 3 阶段会有更详细的文档）

- **NpcTalkItem**：每句对话一行。`NpcId` 是说话的人，`NextTalkId` 接下一句；`NextTalkType` 为 `Option` 时 `NextTalkId` 写多个选项（逗号分隔）。`Type` 是 `Dialog`（对白）、`Narrator`（旁白）等。
- **QuestItem**：任务。`QuestType` 为 `Parent`（主任务）/ `Son`（子任务），主任务的 `QuestSequence` 列出它的子任务。
- 剧情演出是 `Config/Cinematic/{Id}.json`，由节点组成，对话节点是 `{ 'TalkAction' : '对话Id'}`。
