# 剧情（规划中）

写剧情的工具还在做（第 3 阶段）。这里先说清楚游戏的剧情是怎么组成的，以及我们打算怎么让写剧情变简单。
想参与讨论的，欢迎在 Issues 里开帖。

## 游戏的剧情由什么组成

| 部分 | 在哪 | 作用 |
|---|---|---|
| 对话 | NpcTalkItem 表 | 每句话一行：谁说、说什么、表情、下一句是哪句、选项 |
| 任务 | QuestItem 表 | 任务名、简介、地点、主任务 / 子任务、完成奖励 |
| 演出 | `Config/Cinematic/{Id}.json` | 一串节点：黑屏淡入淡出、移动镜头、角色走位、播动作、**开对话**、发奖励、开任务、进战斗…… |
| 触发 | 场景触发区、NPC 行程（`Config/Schedule/`）、事件表（GameEvent 等） | 什么时候、在哪里开始播某个演出 |

演出 json 长这样（节选，`Next` 是下一个节点的序号）：

```json
{ "Node": "{ 'ScreenFadeAction' : False, 1.00000} ", "Next": 1 },
{ "Node": "{ 'TalkAction' : 'mh210000_0000'} ", "Next": 2 },
{ "Node": "{ 'StartQuestAction' : 'qh2100', True, False, False} ", "Next": -1 }
```

手写这种东西很痛苦，所以要做工具。

## 打算怎么做

1. **剧本格式**：用接近写小说的方式写一段剧情，例如

   ```
   [黑屏淡入]
   老掌柜：这位少侠，后山那伙山贼又下来了，能否帮小老儿一把？
   主角：
     > 包在我身上。    -> 接受
     > 与我何干？      -> 拒绝
   [开始任务 zs_q001]
   ```

   工具把它自动转换成 NpcTalkItem 的对话行 + 演出 json，放进你的内容包。
2. **触发**：先支持最常见的几种——和某个 NPC 对话时、进入某个场景时、完成某个任务后。
3. **测试热键**：游戏里一键播放指定演出，不用从头玩到那里。
4. 文档：演出节点大全（每种节点做什么、参数是什么）。

在这之前，如果你已经想好了故事，可以先写成文字大纲，在 Issues 里发出来，等工具好了直接转。
