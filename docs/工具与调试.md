# 工具与调试

## 热键

所有热键都能在 F1 配置界面（或 `BepInEx\config\gulong.openmod.cfg`）里改。

| 热键 | 功能 | 配置分组 |
|---|---|---|
| **F5** | 重新加载所有内容包（表格、图片、改招），不用重启 | 内容包 |
| **F6** | 招式预览窗口：列出所有招式、播放演出、看特效名和命中时间；PageUp / PageDown 切换 | 招式预览 |
| **F7** | 重新读取改招 json | 改招 |
| **F9** | 推理一键完成 | 推理 |
| **F10** | 让角色学会「学会招式ID」里的招式（逗号分隔可写多个） | 武学测试 |
| **Ctrl+F10** | 把「发放道具ID」里的道具放进背包（道具 Id 或奖励 Id，`id*3` 表示 3 个） | 武学测试 |
| **F11** | 进入测试战斗（默认 `xk_test`：木桩，需要 `devtools` 包）。**先存档** | 武学测试 |
| **F12** | 把「导出演出名」的演出结构导出到 `BepInEx\timeline_dump\` | 武学测试 |

## 开发目录：直接读仓库里的内容包

做内容时，与其改完再复制到 `游戏目录\Mod\Packs\`，不如让插件直接读你正在编辑的那份：

F1 → 内容包 →「开发目录」填你的 `packs` 文件夹，例如 `D:\GuLongOpenMod\packs`（多个用分号分隔），按 F5 或重启游戏。

- 同一个包（id 相同）开发目录里的优先，`Mod\Packs` 里的旧副本自动忽略；
- 之后改表格、图片、改招 json，保存后按 **F5**（改招也可以按 **F7**）就生效；
- 日志里 `[内容包]   银龙推掌(yinlong) ← …` 那几行会显示每个包实际是从哪读的。

## F5 能刷新什么

- **表格**：原地更新游戏里已有的数据，所以已学会的招式、背包里的道具、NPC 的头像都会看到新值。界面要关掉重开才刷新。
- 从包里删掉的行会恢复成原版的值；新增后又删掉的行要重启游戏才会消失。
- **图片、改招**：立即生效（已经显示在界面上的图片要重新打开界面）。
- **不能刷新**：分布式表（`GameEvent/` 下的）；**正在进行的战斗**——战斗开始时招式、属性会复制一份给战斗单位，改招式伤害、角色属性要退出战斗后进下一场才生效。
- 主角的模型（AvatarItem 的 Model）要重新进场景或重启游戏才会换。

## 日志

`游戏目录\BepInEx\LogOutput.log`，每次启动游戏会重写。和内容包有关的行都以 `[内容包]` 开头：

```
[内容包] 已加载 2 个：开发工具(devtools) 1.0.0，银龙推掌(yinlong) 1.0.0
[内容包] SkillItem：银龙推掌(yinlong) 新增 1 行，修改 0 行
[内容包] CharacterPropertyItem：开发工具(devtools) 新增 0 行，修改 1 行
```

常见的警告：

| 日志 | 意思 |
|---|---|
| `有原表没有的列「Skil」` | 表头列名拼错了（大小写无所谓，字母要对） |
| `新增的 xxx 不是以登记的前缀开头` | 新 Id 没用 pack.json 里的 idPrefix |
| `xxx 同时被 A 和 B 改了` | 两个包改了同一行，后加载的为准 |
| `覆盖了 A 的文件 …` | 两个包放了同一路径的文件 |
| `游戏里没有表 …` | 表名拼错，或者想新建一张游戏里不存在的表（不支持） |

想知道游戏到底从内容包里读了哪些文件：F1 → 内容包 → 打开「记录资源读取」。

## 校验工具

提交前在仓库根目录跑（需要 Python 3）：

```
python tools/validate.py
```

它会检查：pack.json 格式、表格编码和 Tab、表头有没有 Id、Id 重复、Id 前缀和别的包重叠、改招 json 格式。
GitHub 上提交 PR 时也会自动跑同样的检查。

### 对照原版表做更多检查（可选）

如果你手上有解包出来的原版表（见下节），可以多做几项检查：列名是否存在、新 Id 有没有用自己的前缀、
书引用的招式是否存在、奖励发的道具是否存在、图标文件是否齐全：

```
python tools/validate.py --tables "D:\解包\config\textfiles(sc)"
```

再加 `--dump 输出目录`，会把合并后的整表写出来，方便对照和复制原版的行。

## 查看原版表格

游戏的表格打包在资源文件里。想看原版数据（找某个招式的数值、某段对话的 Id 等），可以用
**AssetRipper** 之类的 Unity 解包工具导出游戏目录里的资源，表格在导出结果的 `config\textfiles(sc)\` 下，
都是 Tab 分隔的文本，用 Excel / WPS 打开最方便。

> 解包出来的东西只用来查资料，**不要提交到仓库**。
