# 安装

需要：正版《古龙风云录》（Windows），能联网下载以下几个免费工具。

## 1. 安装 BepInEx 5

1. 到 BepInEx 的 GitHub Releases 页面下载 **BepInEx 5.4.x 的 win_x64 版本**（文件名形如 `BepInEx_win_x64_5.4.23.2.zip`）。
   注意是 **5.x**，不要下 6.x（BepInEx 6 的插件接口不一样）。
2. 把压缩包里的东西解压到 **游戏目录**（和 `GuLong.exe` 同一层），解压后应该有 `BepInEx\`、`winhttp.dll`、`doorstop_config.ini`。
3. 运行一次游戏再退出。游戏目录里出现 `BepInEx\LogOutput.log`、`BepInEx\plugins\` 就说明装好了。

Steam 版游戏目录一般是 `D:\Steam\steamapps\common\古龙风云录`（右键游戏 → 管理 → 浏览本地文件）。

### 可选：游戏内配置界面

装上 **BepInEx.ConfigurationManager**（GitHub 搜索同名项目，下 BepInEx 5 版本，解压进 `BepInEx\plugins\`），
游戏里按 **F1** 就能打开所有设置。不装也行，直接用记事本改 `BepInEx\config\gulong.openmod.cfg`。

## 2. 编译插件

1. 安装 **.NET SDK**（8.0 或更新，微软官网下载）。装好后在命令行输入 `dotnet --version` 能看到版本号即可。
2. 下载本仓库（GitHub 页面 Code → Download ZIP，或者 `git clone`）。
3. 进入仓库的 `plugin\` 目录，把 `GameDir.props.example` 复制一份，改名为 `GameDir.props`，用记事本把里面的路径改成你的游戏目录。
4. **关闭游戏**，在 `plugin\` 目录打开命令行，运行：

   ```
   dotnet build -c Release
   ```

   第一次会自动下载编译需要的东西，稍等一会儿。最后显示「生成 成功」就完成了，
   插件和仓库里所有内容包都已经自动放进游戏目录（`BepInEx\plugins\GuLongOpenMod\`、`Mod\Packs\`）。

   想看到复制了哪些东西，加上 `-tl:off`：`dotnet build -c Release -tl:off`，输出里会有「插件已复制到…」「内容包已复制到…」。

   - 不想自动复制内容包：`dotnet build -c Release -p:CopyPacks=false`
   - 不想建 GameDir.props：`dotnet build -c Release -p:GameDir="D:\Steam\steamapps\common\古龙风云录"`

> 一定要先关游戏再编译。游戏开着时插件文件被占用，复制会失败，游戏里跑的还是旧版本。

## 3. 确认装好了

进游戏后打开 `BepInEx\LogOutput.log`，能看到类似：

```
[内容包] 已加载 2 个：开发工具(devtools) 1.0.0，亢龙有悔(yinlong) 1.0.0
补丁完成：成功 N 个，失败 0 个
古龙风云录 开放 Mod 0.1.0 已加载
```

## 安装 / 卸载内容包

- 安装：把内容包文件夹（里面有 `pack.json` 的那一层）放进 `游戏目录\Mod\Packs\`。
- 临时关掉：F1 配置里「内容包 → 禁用的包」写上包的 id，或者直接把文件夹移走。
- 只做给自己玩、不打算公开的东西（比如替换原版角色立绘），也可以做成内容包直接放在 `Mod\Packs\`，不用提交到仓库。

## 卸载

删除 `BepInEx\plugins\GuLongOpenMod\` 和 `Mod\Packs\` 即可。想彻底还原就再删掉 BepInEx（`BepInEx\`、`winhttp.dll`、`doorstop_config.ini`）。

**存档提醒**：用了内容包里的道具/招式后存的档，卸载内容包后这些东西会找不到。重要存档请先备份（一般在 `游戏目录\SaveData\`，没有的话以你电脑上实际位置为准）。
